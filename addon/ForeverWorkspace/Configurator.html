Peripheral · Development prototype

Keep the world on one screen.

Helper-free fallback: plan your side strips, copy a configuration into WoW, then align the game window. The Windows helper is the primary setup option when available. This page works directly from a local file and sends no data to a server. No Windows helper, Node.js or local server is needed.

1. Set up your monitors

Start by detecting your monitors or entering their measurements.

Monitor measurements

Browser screen rectangles use CSS/logical pixels. The addon needs physical desktop/client pixels. Browser zoom and Windows scaling are different. Uniform per-screen scaling can provide a candidate conversion; mixed scaling requires manual physical coordinates. Always verify the physical values against Windows Display settings.

All editable numbers are physical pixels. Negative desktop X/Y values are valid. Work insets reserve taskbars/docks; zero means no reservation. Browser labels and list numbers are not guaranteed to match Windows monitor numbers.

2. Choose the game screen and side strips

Window border allowance (optional)

Adjust the outside of the target client footprint (negative horizontal values add padding) to allow room for a bordered window. Main keeps its physical width; top/bottom trims can reduce its height. These values do not move or measure WoW. You can instead use Fit current window in /fws align after manually resizing near the target.

This version supports horizontal left/right monitors, including unequal heights and vertical offsets with overlapping heights. The rectangular WoW window also covers any empty gaps inside its footprint.

3. Set up WoW

Confirm the monitor measurements above to enable copying.

Show configuration text
  1. Set WoW to standard Windowed mode. Run /peripheral import, paste the configuration, and choose Import / save only.
  2. Run /peripheral align. Resize the game window near the target size shown above. Use Fit current window for a close match, then move the window until the green guides line up with the game monitor.
  3. Choose Apply trial → Keep. On later sessions with the same layout, choose Use saved layout.
Alignment help

The target size is the client area inside the borders and title bar. Fit can accept a width within 256 pixels and a height up to 256 pixels shorter. It saves geometry without resizing the window. Amber guides indicate a size mismatch. The page cannot measure the WoW window's position. On Windows, Alt+Space → Move can help position it.

Cancel or let the trial time out to restore the viewport. Use Center Blizzard HUD after Keep if you want to move supported Blizzard panels back to Main.

Updates, display changes and recovery

Monitor configuration is saved in WoW SavedVariables, not installed addon files. Replacing addon files preserves that configuration and panel preferences. Login/reload still starts the viewport disabled.

When detected screens change, this page invalidates the output. Redetect, or choose manual values and verify them again. The addon cannot enumerate Windows monitors; after unplugging/rearranging screens, cancel/reset, regenerate configuration and align again. If the client size changes, the addon rejects stale geometry. A same-size physical display change cannot be automatically detected by the addon.

Old generated Geometry.lua can be migrated if it is still loaded once. A saved /fws diag can also provide a bounded snapshot, marked as potentially stale. Verify it with alignment or import a fresh configuration. If neither data source remains, use a backup or create a new configuration.

Optional Windows helper

Start Peripheral detects WoW and places its window. First setup creates a small companion addon; restart WoW once if it is already open. For an unchanged layout, use Start Peripheral in Windows, then Use saved layout in WoW.
